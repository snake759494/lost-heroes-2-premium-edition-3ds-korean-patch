# 글꼴

| 용도 | 글꼴 | 비고 |
| --- | --- | --- |
| 게임 본문 폰트(14×16 칸) | 나눔스퀘어네오 Bold, 14px | 원본 고딕 비트맵과 획 굵기가 가장 비슷함 |
| 게임 소형 폰트(12×12 칸, 이름표·결과 화면) | 나눔스퀘어네오 Bold, 10px | 칸 안 1~10행에 맞춰 잘림·번짐 방지 |
| 엔딩 스태프롤 폰트(15×16 칸) | 서울한강체 M, 14px | 원본이 명조체 |
| 그림 글자(로고·메뉴·UI) | 나눔스퀘어네오 Heavy / ExtraBold / Bold 등 | 원본 색·그라데이션·외곽선·글로우에 맞춰 렌더링 |

- 나눔스퀘어네오: 네이버 — 나눔글꼴 라이선스
- 서울한강체: 서울특별시 — 서울서체 이용 조건

글꼴 파일은 저장소에 포함하지 않습니다. 빌드하려면 저장소 상위 작업 폴더에 `NanumSquareNeo-*.ttf`, `SeoulHangang*.ttf` 를 두세요(또는 환경 변수 `LH2_FONT_DIR`).
